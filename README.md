### What is Mr.Todos??

Mr.Todos can help managing your daily busy schedule. You can track your activities/tasks using Mr.Todos smartly. Mr.Todos also allows users to prioritize tasks while adding. Users can change the priority whenever they want at later point of time. Mr.Todos has a reminder feature, which will remind you of pending tasks as well.

### Mr.Todos is equipped with following features:
* Social Sign ins
* easy Sign up with email
* User Profile management
* Task Tracking
* Prioritize Tasks
* Edit task details
* Duplicating task
* Task History
* Customer support with email
* Dark Theme
